An entry for the [make.fun bounty "Sum up 21 November's world news in one image"](https://make.fun/bounty/news-image-20261121): one front page summing up Saturday 21 November 2026 — Russian missiles land in Poland, the World Court's Rohingya genocide ruling, the Trump–Xi–Putin summit, markets sliding into correction, a magnitude 6.8 quake in Peru, and 20 more verified stories from every region, with a pinned world map.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) copies the rendered `entry.png` (1024×1024, deterministic, no network) to the output directory.
